# Портфолио

Сайт-витрина всех работ из папки «Верстка». Чистые HTML/CSS/JS.

## Запуск

```
npx http-server -p 5180 -c-1 .
```

Ссылки «Смотреть» ведут на опубликованные сайты (GitHub Pages), «Код» на репозитории. Для локальной проверки всех проектов сразу запусти сервер из папки `Верстка`:

```
cd ..
npx http-server -p 5180 -c-1 .
```
и открой `http://localhost:5180/Портфолио/`.

Опубликовано: https://k0lumiq.github.io/portfolio/ (репозиторий K0lumiQ/portfolio).

## Как добавить работу

1. Сделать скриншот главной страницы работы (16:10, например 1280×800) и положить в `img/<имя>.jpg`.
2. Добавить объект в массив `window.WORKS` в `works.js` (название, описание, стек, preview, live, code).
3. Карточка появится в сетке сама.
