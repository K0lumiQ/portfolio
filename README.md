# Портфолио

Сайт-витрина всех работ из папки «Верстка». Чистые HTML/CSS/JS.

## Запуск

```
npx http-server -p 5180 -c-1 .
```

Ссылка на Classy Store сейчас относительная (`../Classy Store/index.html`), поэтому сервер надо запускать из папки `Верстка`, а не из `Портфолио`:

```
cd ..
npx http-server -p 5180 -c-1 .
```
затем открыть `http://localhost:5180/Портфолио/`.

## Как добавить работу

1. Сделать скриншот главной страницы работы (16:10, например 1280×800) и положить в `img/<имя>.jpg`.
2. Добавить объект в массив `window.WORKS` в `works.js` (название, описание, стек, preview, live, code).
3. Карточка появится в сетке сама.
